# uzunyx-keys

Ventana con todos los atajos del escritorio: `Super+Space`, «Atajos de Uzunyx» en
el menú, o el botón del módulo de Uzunyx en Configuración del sistema. La misma
tecla o Esc la cierran.

Lee las teclas de kglobalaccel al abrir (`shortcutKeys`), así que muestra las
que hay de verdad, también las que el usuario cambió; lo que no tiene teclas o
no está instalado no aparece. La lista de acciones está en `SECTIONS`: al agregar
un atajo a `uzunyx-shortcuts` o a un script, sumarlo ahí.

El mosaico no la toma y le quita la barra de título (`uzunyx-tiling` ≥ 0.5.1): queda flotante, con el borde y las esquinas de `uzunyx-outline`, y se arrastra desde cualquier espacio vacío.
